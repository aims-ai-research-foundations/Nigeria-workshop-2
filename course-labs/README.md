# Course Labs

Notebooks for the end-of-day **Course Lab** sessions (17:00–18:00 WAT, except
Day 5 where the Course 7 lab runs 14:30–15:30), organised by day. Click an
**Open in Colab** badge to launch a notebook directly in Google Colab — no
local setup required.

Days 1–2 are live; the remaining Cohort 2 copies land here as they are frozen.
Days 1–4 run on CPU with no setup; the Day 5 lab needs a Colab **T4 GPU** and
a Hugging Face token — setup steps will land in [day5/](day5/) before the
session.
